# MD2.A1 card — repository-owned region generation

2026-10-30. Owner Codex; challenger Claude. **Frozen r0 before implementation, pending independent challenge.** Base `af72dbe`, branch `feat/md2a`, project `.worktrees/md2a`. [Design](../../superpowers/specs/2026-10-30-atlas-md2a1-generation-ownership.md), [plan](../../superpowers/plans/2026-10-30-atlas-md2a1-implementation.md).

**Experience:** launch ATLAS and navigate Regression World using project-owned generation code/inputs, without importing first-party scratch experiments. Regression World can evolve with validation requirements; this migration uses the existing definition as a temporary compatibility control.

**Limitation/risk:** the working application still imports a chain of scratch builders/data and one path-bearing legacy world. Rebased source may silently change math, load order/caches, source qualification or old saved-place compatibility. Copying code is not proof of generalized world creation. Existing canonical base includes one historical unresolved-to-zero sample; preserve provenance and do not generalize that policy.

**Smallest workload:** static dependency/math/legacy binding checks; guarded units/build; one exclusive-GPU native five-case migration/qualification and order/rebuild control; completed independent review; one pinned maintained headed full gate with all current application workflows. Actual source/input ownership must be recorded. Scratch outputs/caches/installed third-party environments are allowed; scratch first-party generation/reference source and world-input reads are not.

| Criterion | Success evidence |
|---|---|
| Source/input ownership | Runtime and independent qualification load first-party mathematical/helper code and declared fixtures from the repository; actual module/input roots and hashes agree with the manifest. |
| Mathematical compatibility | Mathematical function bodies/CUDA unchanged where relocated; same-host home/new3D/corner/fine/view buffer controls match; canonical world, sampling, tolerances, body/domain and rules unchanged. |
| Legacy/source identity | Exact legacy world asset bindings verified against archived original source/input bytes; adapted executable digests separate; old actual scene files remain compatible. New builder keys are explicit. |
| Regeneration/ownership | Opposite order, reuse, rebuild and stale epoch controls pass within new source; caches/job/output/region ownership bounds unchanged; every publication retires and all owned cleanup confirmed. |
| Qualification integrity | Newly derived coarse/fine/view certificate binds actual relocated source/dependencies and preserves finite coverage limits; wrong/old certificate rejects. No fine fixture mesh used as runtime geometry. |
| Product behavior | Current normal contact/scale, session/launcher, files/history/recovery and maintained Plane/viewer gate entries pass on the pinned migration head. |
| Performance/resources | Report ≥30 FPS overall/preparation, nav p99 ≤2 ms/max ≤8 ms, interaction readiness ≤1 s and attributable region memory ≤1 GiB individually as pass/miss/unverified. Existing misses may remain; restore/recovery waits separately; no new tail/artistic gate. |
| Process/claims | Complete independent card/evidence judgement; established/partial/unresolved findings, exact source/file/run hashes, review scope and process cost. A1 is runtime ownership; canonical-input creation, new recipes/multiple worlds/Plane workflow remain A2/A3. |

**Bounds/stop:** ≤4 h source/CPU, ≤1 h hardware/evidence including one ≤45 min full gate; adequate completed review time separate. One outcome-independent preflight mechanical repair, failed attempt preserved. Stop qualification for safety, unintended world change, lost ownership, unconfirmed cleanup or bound exhaustion. Do not rerun for a better score. No browser/headless/software substitute, GPU overlap, hidden acceptance waiver or new backend/default. Advisor merges.

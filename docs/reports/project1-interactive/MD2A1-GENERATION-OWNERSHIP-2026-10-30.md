## What the current recipe contains

Today “recipe” means a fixed bundle of mathematical code, numeric parameters and required input assets. It includes fixed Mandelbrot source coordinates/spatial mapping, precomputed parent samples (`base.npz`) and frame, child/grandchild construction transforms and carving parameters, and a smaller descendant's chart centre/support/amplitude/source ratio. The helper supplies a world record with ID, generator/version, descendant parameters, lineage and six asset digests. That record is not yet a complete self-contained input recipe. The browser consumes it and requests prepared regions; it does not create a new definition from the current Plane location. The merged implementation assembled that record from scratch; A1 loads the owned bundle and preserves its definition literally. Geometry continues to be computed by the local native helper.

## Preparation and measured scope

A local Node adapter verifies a complete resolved bundle and prepares a whole small static heightfield. It creates coarse, fine and view normalized buffers; Rapier and WebGPU consume the same top triangles. The closed bottom/sides provide occupancy inside the finite bounds. CPU/native geometry preparation from already GPU-created canonical arrays does not repeat Mandelbrot evaluation during movement. The independent CPU preflight, including both meshes, dumps and checker, completed in **0.762 s** against its 180 s bound. Source creation remains the owned CUDA A2.1 mechanism.

The helper shares immutable producer buffers for each kind. Existing consumer lifecycle still indexes/uploads separate copies for resident addresses. Source phases publish/retire 19,23,5,5 artifacts; median readiness is about34 ms, with first/restore instances around250 ms. This is an intentionally small whole-world representation. It does not establish broad-world streaming, large-world memory bounds, arbitrary source support or performance of recursive formations.

The source-specific certificate binds the actual representation sources, Node version, definition/logical input and exact buffer descriptors. Mathematical input keys exclude process/path/provenance, so a mathematically identical relocated/rebuilt bundle remains the same world; transport hashes are still checked. Only the qualified A/B definitions/policy are admitted. Existing creator/evaluator/worker/fixture/certificate bytes remain unchanged.

The default Regression World route was also remeasured: overall **38.275 FPS**, resident navigation p99 **4.200 ms** / maximum **4.500 ms**, maximum readiness **2.198 s**. FPS and navigation maximum pass; p99/readiness still miss their2 ms/1 s targets, and regional memory remains unverified. The parent and regression routes have different geometry and input workloads; these are individual acceptance measurements, not a controlled speedup comparison.

## Experience and scope

Enter that world, move in three dimensions, contact its terrain, change body size without moving the terrain or visitor, save a place, and reopen it after restarting the helper/browser. Regression World remains the default and retains its existing scene behavior. One configured world per launch; Plane creation UI and a world registry remain A3.

This decomposes A2.2: **A2.2a connects parent recipes to an actual experience first; A2.2b retains authored recursive/imported closure and the A2.1 Python negative/integral-float/status-3/status-4 follow-ups.** The full foundation remains open. ## Smallest preparation path

Use a new local Node source adapter supplied to the existing application server. Read the portable A2.1 bundle, verify transport hashes, exact recipe/request/definition keys, numeric array format and logical array digest. A bounded numeric-only NPY v1 reader accepts only little-endian float64, C order, the declared square shape and finite nonnegative-zero values. Reject extra/unsafe filenames, symlinks escaping the bundle, malformed headers, trailing/truncated data and nonresolved results. No eval, pickle, native generator import or mathematical iteration occurs in this adapter.

Build the whole small terrain once per representation: 4225 top vertices and 8192 top triangles for the existing 64-cell sources; duplicate the grid at the fixed bottom for a closed solid (8450 vertices, 16896 triangles including 512 side faces). With rows increasing z and columns increasing x, cell indices a=(j,i), b=(j,i+1), c=(j+1,i), d=(j+1,i+1) yield top faces (a,c,b), (b,c,d). Reverse top faces for the bottom and reverse each oriented boundary edge for side quads. Render/cast the top; use the entire closed solid for occupancy. Every undirected solid edge must have two oppositely directed uses; signed volume must be positive and within the global bounding volume.

Prepare coarse interaction, fine interaction and view buffers. Existing casts require normalized body diameter one: coarse scale D=0.1 m, fine D/4=0.025 m, view scale 4D. The physical triangles remain the same because these scales differ by exact powers of two; normalized bytes/revisions differ. Each artifact's render/collision revision must agree **within that artifact**, not across intents/scales. Each address owns a separate existing consumer lease; record the duplicate index/upload cost. This is bounded whole-world preparation, not broad-world streaming. No new Python worker or controller change is needed.

Use a new discriminated `bilinear-grid-v1` sampling record with cells, stepM, tileWidthM, maxSurfaceErrorM and the existing coordinate type. Preserve acceptance and serialized values of the legacy RTIN record. The declared `qualification.toleranceM` is fixed at 1.25e-5 m in every artifact; `maxSurfaceErrorM` records the actual calculated bound. Qualification stays `empirical`; analytical interpolation/roundoff calculations are supporting evidence, not a change to the preparation contract's claim strength.

## Coordinates, entry and coverage

Y is up; canonical source domain is x/z ±0.8 m. Global bounds are x/z domain and [minH−1,maxH+1] in y; bottom is the lower y bound. Entry x/z comes from a 0.2 m offset along the actual centre normal. Entry y is the maximum canonical height over an enclosing grid rectangle of the body's XZ footprint plus 0.6D. Actual prepared clearance still decides admission; no flat-terrain assumption. The grid and mesh anchor is that entry; the target is the actual source centre. Derive finite axis-aligned half-D body and view grids inside the global bounds. Fine bounds use the same global AABB; existing home residency/grow requirements remain satisfied by globally covering home geometry.

Before admission, enumerate **every** coarse/view address and check its requested cube lies in the artifact bounds. Check the whole pose model envelope is contained, including fine poses and entry. Predictions cannot generate an out-of-bounds address that would turn `unsupported` into a fatal runtime error. Body/sweep containment prevents leaving the geometry domain. Additionally expose `poseModel.supportsPositionM(position, bodyDiameterM)` using the same finite coarse envelope/fine limits as validation; runtime checks the proposed move before committing it and returns `waiting: true, reason: finite-domain` instead of throwing. The workspace reports the finite boundary. This closes the reverse-containment gap for fine bodies: global collision coverage is larger than the coarse-derived pose envelope. Keep full artifact bounds/solid volume honest rather than narrowing bounds around an unclipped solid. Check both coverage directions and actual fine boundary input; no session interruption. Grid axes are explicitly X, Z, Y (orthonormal; no handedness assumption).

For each canonical cell, bilinear-to-triangle vertical error is |h00−h01−h10+h11|/4. Add actual maximum float32 coordinate displacement: δy + max|∂H/∂x|δx + max|∂H/∂z|δz, plus 1e-12 m arithmetic allowance. Require total ≤0.0005×fineD=1.25e-5 m for all three representations, half the existing fine collision skin. Bounds concern the interior supported domain, not extension beyond the source boundary. A/B read-only design calculation found about 5.44e-6/1.027e-5 m, including lateral displacement; implementation is independently checked again. Failure is unsupported, not permission to invent a finer grid after seeing results.

## Identity, qualification and application

Embed the complete canonical parent definition in the generic world record. Bind its logical array SHA explicitly; executable/package/path/process/camera/body/cache information stays outside world identity. Portable scene v1 uses `source-parent-global-r1` coverage and `source-parent-bilinear-r1` sampling only for this generator. Its fixed unit light is [-1/3, 2/3, -2/3] (binary64 components supplied by the adapter). It accepts source-only coverage/sampling labels for this generator; legacy labels remain unchanged for legacy worlds. Wrong configured world remains explicit unsupported, never aliased to the available terrain.

A source-specific certificate binds actual adapter/reader/mesh/contract/scene source digests, Node version, complete definition/logical input keys and qualified specimen metadata. Only the checked A/B definitions are admitted. Preflight mode can expose unqualified data to the independent checker but cannot admit it for application flight. Pin certificates after independent CPU checks and before the final clean source freeze. Do not reuse the legacy certificate or self-award runtime qualification. Certificates themselves are excluded from source keys to avoid a circular digest. Altered inputs/sources/policy must fail closed.

Add `--source-world <bundle>` to the owned launcher and a corresponding server configuration seam. This chooses the source adapter and source certificate explicitly, never the legacy fallback certificate. Source adapter supplies setup approach/feature/light metadata; default adapter retains the existing feature-file path and `/open` values. No arbitrary file access is added to HTTP. Existing client ownership, nonces, heartbeats, publication retirement, cancellation, epochs and shutdown remain in force. Source adapter has no child process; close releases its buffers/publications and records cleanup.

The penetration stop rule is delivered-mesh distance ≥ body radius − s, where s = 8×2^(floor(log2(max(1,maxAbsNormalizedVertex)))−23)×metresPerUnit (eight float32 ulps at the largest normalized vertex). Separately report the conservative true-surface clearance lower bound, mesh distance − body radius − calculated source error, with expected lower limit −(s+source error); this supporting approximation finding is not a stronger collision guarantee. The direction-of-motion backoff does not guarantee a full skin of normal clearance during grazing contact; do not audit against a locally flat plane. Existing A2.1 generation/math evidence is reused with checked hashes: no new GPU regeneration claim is made here.
